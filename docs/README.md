# pytest-agentcontract Documentation

This directory contains task-focused documentation for using
`pytest-agentcontract` in a pytest suite.

Start with:

- [Getting Started](getting-started.md) for installation, a minimal test, and the
  record/replay workflow.
- [Configuration](configuration.md) for the supported `agentcontract.yml`
  sections and defaults.
- [Assertions and Policies](assertions-and-policies.md) for contract checks,
  target syntax, and built-in policy behavior.
- [Cassette Format](cassette-format.md) for the `.agentrun.json` structure.
- [Adapters and Interceptors](adapters-and-interceptors.md) for manual recording,
  SDK interceptors, and framework adapters.
- [CLI](cli.md) for the `agentcontract` command and pytest plugin options.

The bundled example is documented separately at
[`examples/customer_support/README.md`](../examples/customer_support/README.md).
