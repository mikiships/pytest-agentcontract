# Cassette Format

Recordings are JSON files named with the `.agentrun.json` suffix. The serializer writes a JSON-compatible representation of `AgentRun`.

## Compact Example

```json
{
  "schema_version": "1.0.0",
  "run_id": "2f2ff983-2f45-4c48-83f3-6c31f1d762ab",
  "source": {
    "recorded_at": "2026-06-16T12:00:00+00:00",
    "recorder_version": "0.1.1",
    "sdk": "agentcontract-python"
  },
  "model": {
    "provider": "openai",
    "model": "gpt-4o",
    "temperature": 0.0,
    "top_p": 1.0,
    "max_tokens": 4096,
    "seed": 42
  },
  "metadata": {
    "scenario": "refund-eligible",
    "tags": ["refund"],
    "description": "Delivered order refund flow"
  },
  "summary": {
    "total_turns": 3,
    "total_duration_ms": 231.4,
    "total_tokens": {
      "prompt": 100,
      "completion": 40,
      "total": 140
    },
    "total_tool_calls": 1,
    "estimated_cost_usd": 0.0
  },
  "turns": [
    {
      "index": 0,
      "role": "user",
      "content": "Refund order ORD-123"
    },
    {
      "index": 1,
      "role": "assistant",
      "content": "Looking up your order.",
      "tool_calls": [
        {
          "id": "tc_lookup",
          "function": "lookup_order",
          "arguments": {"order_id": "ORD-123"},
          "result": {"status": "delivered", "total": 49.99},
          "duration_ms": 8.5
        }
      ],
      "timing": {
        "latency_ms": 150.0,
        "time_to_first_token_ms": null
      },
      "tokens": {
        "prompt": 100,
        "completion": 40,
        "total": 140
      }
    },
    {
      "index": 2,
      "role": "assistant",
      "content": "Your refund of $49.99 has been processed."
    }
  ]
}
```

## Top-Level Fields

`schema_version` defaults to `"1.0.0"`.

`run_id` is generated by `Recorder` as a UUID string.

`source.recorded_at` is the recording timestamp. `source.recorder_version` is the package version. `source.sdk` defaults to `"agentcontract-python"`.

`model` stores provider, model name, temperature, top-p, max token limit, and seed. Manual recordings may leave provider/model empty.

`metadata.scenario` is the scenario name. `metadata.tags` is a list. `metadata.description` is free-form text.

`summary` stores total turns, duration in milliseconds, aggregate tokens, total tool calls, and estimated cost. The recorder computes turn count, duration, tokens, and tool-call count when the recording context exits. Estimated cost currently defaults to `0.0`.

`turns` is the ordered trajectory.

## Turn Fields

Each turn has an `index` and `role`. Valid roles are `system`, `user`, `assistant`, and `tool`.

`content` is optional. When present it is serialized as a string.

`tool_calls` is optional and only emitted when the turn has tool calls. Each tool call stores `id`, `function`, `arguments`, `result`, and optional `duration_ms`.

`timing` is optional and stores `latency_ms` and `time_to_first_token_ms`.

`tokens` is optional and stores `prompt`, `completion`, and `total`.

## Required Versus Optional In Practice

The loader is intentionally tolerant for older or hand-edited cassettes. It defaults missing top-level sections, missing turn indexes, nullable timing/tokens/tool-call lists, and many scalar fields.

A replayable cassette should include at least:

- `turns` with valid `role` values.
- Tool calls with `function` and object-like `arguments` when you want tool assertions or stubbing.
- Tool-call `result` values when you want `ReplayEngine.tool_stub.get_result()` to provide useful results.
- `metadata.scenario` when you want scenario-specific overrides to match the run.

`agentcontract validate <path>` checks that the cassette can be loaded by the current serializer. It is not a semantic contract check.
